# Trusted Intake Connector — G3F Failure-Injection Matrix

Failures are injected via `connector-instrumentation.ts`'s test-only hook
(`__setConnectorFaultHook`) at labelled points inside the importer's single
transaction, plus out-of-band techniques (connection termination via
`pg_terminate_backend`, real `statement_timeout`/`lock_timeout`, direct DB
mutation between operations — the same techniques G3E's tests already used).
Production registers no hook: each labelled point is a single `if (hook)`
check with zero behavioural change.

**Core invariant across every row:** because the importer's reservation →
owner resolution → reference allocation → submission insert → item inserts →
mapping completion → connector `imported` transition → event write → attempt
row are all **one** `withConnectorTx` transaction, any fault _before commit_
rolls back every write it made (connector stays `ready_for_import`, no
mapping completed, no destination, no attempt row). So most "fail after step
X but before commit" rows collapse to the same safe outcome.

| #   | Injected failure                              | Mechanism                                                                                                                                                                                                   | Expected DB outcome                                                                                                                                                                                                              |
| --- | --------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Before claim                                  | worker throws before `claimNextConnectorRecord`                                                                                                                                                             | no claim, no mapping, no destination                                                                                                                                                                                             |
| 2   | Immediately after claim                       | hook throws at `after_claim` (in the claim txn)                                                                                                                                                             | claim txn rolls back → record not claimed; lease never set; still claimable                                                                                                                                                      |
| 3   | After lease renewal                           | hook at `after_lease_renewal`                                                                                                                                                                               | renewal committed independently is fine; a throw after it just aborts the caller — no import side effect                                                                                                                         |
| 4   | Before validation recheck                     | hook at `before_validation_recheck` (import txn)                                                                                                                                                            | import txn rolls back; connector stays `ready_for_import`; no destination                                                                                                                                                        |
| 5   | After validation recheck                      | hook at `after_validation_recheck`                                                                                                                                                                          | same — rollback, no destination                                                                                                                                                                                                  |
| 6   | Before reservation                            | hook at `before_reservation`                                                                                                                                                                                | rollback, no mapping row, no destination                                                                                                                                                                                         |
| 7   | After reservation                             | hook at `after_reservation`                                                                                                                                                                                 | rollback → the `reserved` INSERT is undone (same txn); no orphan reservation; retry re-reserves cleanly                                                                                                                          |
| 8   | After owner resolution                        | hook at `after_owner_resolution`                                                                                                                                                                            | rollback → owner `users` row + link INSERT undone (same txn); **no orphan owner link**                                                                                                                                           |
| 9   | After reference allocation                    | hook at `after_reference_allocation`                                                                                                                                                                        | rollback → allocated `nextval` is burned (documented sequence gap, honest) but no submission created; no duplicate                                                                                                               |
| 10  | After submission insert                       | hook at `after_submission_insert`                                                                                                                                                                           | rollback → submission row undone; mapping not completed; no destination persists                                                                                                                                                 |
| 11  | During item insert                            | hook at `during_item_insert` (after Kth item)                                                                                                                                                               | rollback → submission + all partial items undone atomically                                                                                                                                                                      |
| 12  | After items                                   | hook at `after_items`                                                                                                                                                                                       | rollback → submission + all items undone                                                                                                                                                                                         |
| 13  | Before mapping completion                     | hook at `before_mapping_completion`                                                                                                                                                                         | rollback → nothing persists                                                                                                                                                                                                      |
| 14  | After mapping completion                      | hook at `after_mapping_completion` (before connector→imported)                                                                                                                                              | rollback → mapping completion undone in same txn → connector NOT imported, no destination; retry redoes cleanly. (Architecture is single-transaction, so this does NOT leave a completed mapping without an imported connector.) |
| 15  | Before connector imported transition          | hook at `before_connector_imported`                                                                                                                                                                         | rollback → nothing persists                                                                                                                                                                                                      |
| 16  | Before commit                                 | hook at `before_commit`                                                                                                                                                                                     | no completed destination; connector unchanged                                                                                                                                                                                    |
| 17  | Immediately after commit                      | fault raised by caller AFTER `withConnectorTx` returns                                                                                                                                                      | destination + mapping + attempt already durable; a retry hits `already_completed` and returns the same destination                                                                                                               |
| 18  | After commit, before response (lost response) | harness discards the returned value, then retries                                                                                                                                                           | retry returns the same destination (`already_completed`); zero new submissions                                                                                                                                                   |
| 19  | Worker process termination                    | worker promise abandoned after claim (lease left live)                                                                                                                                                      | lease expires; another worker reclaims (state preserved for `ready_for_import`); the terminated worker's identity can no longer commit (`import_claimant_mismatch`)                                                              |
| 20  | Connection termination                        | `pg_terminate_backend` on the importer's backend mid-transaction                                                                                                                                            | the transaction aborts server-side; `withConnectorTx` sees the error and its `finally` releases (the pool discards the dead client and creates a fresh one); record left `ready_for_import`, recoverable; no partial destination |
| 21  | Transaction timeout                           | `statement_timeout` set low + a deliberately slow step (via hook `sleep`)                                                                                                                                   | statement aborts; txn rolls back; no partial destination; error classified retryable                                                                                                                                             |
| 22  | Lock timeout                                  | `lock_timeout` low + a concurrently-held `FOR UPDATE` on the same connector                                                                                                                                 | second caller's `FOR UPDATE` fails fast (lock_timeout), classified retryable, no duplicate                                                                                                                                       |
| 23  | Expired lease                                 | seed `claim_expires_at` in the past                                                                                                                                                                         | reclaimable by another worker; stale worker cannot commit                                                                                                                                                                        |
| 24  | Stale source mutation                         | mutate customer/card after validation, before import                                                                                                                                                        | import blocked; `stale` attempt row appended; connector → `validating`; no destination                                                                                                                                           |
| 25  | Duplicate request                             | N concurrent imports, same connector                                                                                                                                                                        | exactly one destination; N−1 return `already_completed`                                                                                                                                                                          |
| 26  | Duplicate worker                              | two workers both try the same connector id directly                                                                                                                                                         | connector row `FOR UPDATE` serialises; one imports, the other gets `already_completed`/`import_claimant_mismatch`                                                                                                                |
| 27  | Pool saturation                               | pool `max` < concurrent callers + `connectionTimeoutMillis`                                                                                                                                                 | excess callers queue then time out with a bounded acquisition error; no client leak; no corruption                                                                                                                               |
| 28  | Deadlock (where safely practical)             | not force-induced (the single-lock-order design — connector row always locked first — makes a genuine deadlock between two connector operations structurally impossible); documented rather than fabricated | no deadlock observed; lock-timeout path (row 22) covers the bounded-failure behaviour a deadlock would otherwise need                                                                                                            |
| 29  | Emergency stop mid-run                        | flip `partner_emergency_stop` true during the run                                                                                                                                                           | no NEW claims (assertConnectorActive throws before claim); in-flight txns finish/roll back atomically; no corruption                                                                                                             |
| 30  | Feature flag disabled mid-run                 | flip `partner_connector_enabled` false during the run                                                                                                                                                       | no new work; in-flight finishes/rolls back; fail-closed on restart                                                                                                                                                               |

Rows that are single-transaction rollbacks (2, 4–16, 20, 21) are proven by
asserting the post-fault DB state: connector state unchanged/`ready_for_import`,
zero `partner_connector_imports` completed rows for it, zero `submissions`
rows for it, zero attempt rows for it, then a clean retry succeeds. Rows
17–19, 23–26, 29–30 assert the recovery/idempotency outcome. Row 9's
sequence-gap is asserted as "reference still unique, just non-contiguous" —
disclosed honestly.
